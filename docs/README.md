## Contributing to Documentation

See [CONTRIBUTING.md](../CONTRIBUTING.md) for guidelines on contributing to this documentation.

### Documentation Standards

1. **Every directory has a README.md** — Serves as an index
2. **Clear file naming** — `TOPIC_SUBTOPIC.md` format
3. **Consistent structure** — Each doc has: title, description, content, related links
4. **Cross-references** — Link to related documentation
5. **Examples** — Include practical code examples
